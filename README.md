# House Sales in King County, USA – Data Analysis Project

## Overview

This project analyzes housing sales data from King County, USA, using Python and machine learning techniques. The objective is to explore housing market trends, clean and prepare data, perform exploratory data analysis (EDA), and build predictive models for estimating house prices.

This notebook was completed as part of the IBM Data Science Professional Certificate program. Portions of the notebook structure, instructions, and starter code were provided by IBM for educational purposes. The analysis, code execution, model development, and project completion were performed by me as part of the course requirements.

---

## Project Objectives

* Load and explore real-world housing sales data
* Perform data cleaning and preprocessing
* Handle missing values
* Conduct exploratory data analysis (EDA)
* Visualize relationships between housing features and prices
* Build linear regression models
* Evaluate model performance using R² scores
* Apply Ridge Regression and Polynomial Regression techniques
* Compare model performance and interpret results

---

## Dataset

The dataset contains housing sales records from King County, USA, including features such as:

* Number of bedrooms
* Number of bathrooms
* Square footage
* Waterfront status
* View rating
* House grade
* Location coordinates
* House price
